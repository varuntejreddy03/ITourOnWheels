# India Unveiled

A premium Indian luxury travel platform — editorial, cinematic and culturally immersive.

## Development

Requires Node.js 18+.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Stack

- Vite + React 19
- TypeScript
- TanStack Router (client-side SPA)
- Tailwind CSS v4
- shadcn/ui components
