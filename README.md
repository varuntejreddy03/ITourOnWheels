# India Unveiled

Build the complete travel company website inspired by the attached Trocals reference website/design system.

Use the attached client logo as the brand identity.

IMPORTANT: The provided 7 Days / 6 Nights Luxury Golden Triangle itinerary is ONLY the first/featured trip. Do not design the entire website as if the company only offers this one trip. Build the website structure so more destinations, tours and experiences can be added later.

Overall Direction

Create a premium Indian luxury travel platform with the same editorial, cinematic and immersive feeling as the Trocals reference.

Do NOT clone Trocals. Use it only as the design and UX inspiration.

The website should feel:

Editorial

Luxury

Cultural

Cinematic

Premium

International

Authentic Indian travel

Use the provided Trocals-inspired design system:

Background: #f5f0ea

Text: #2c2422

Primary accent: #d55749

Secondary teal: #8fbcc6

Dark teal: #5e8e9a

Headings: Cormorant Garamond, weight 300

Body: Jost, weight 300

Large editorial typography

Generous whitespace

16px spacing system

Minimal 2–3px radius

Subtle warm/tinted shadows

Smooth scroll animations

Image reveal/parallax effects

Animation & Interaction

The website should feel highly polished.

Use:

Smooth scrolling

Scroll-triggered text reveals

Image clip-path reveals

Subtle parallax

Staggered content animations

Image zoom on hover

Elegant page transitions

Horizontal/vertical editorial movement where appropriate

Sticky sections where useful

Animations must remain subtle and premium. Do not over-animate.

Critical Design Rule

The website should look like a real luxury travel company, not a template.

Prioritize:

Typography + Photography + Whitespace + Editorial Layout + Storytelling

Avoid:

Generic SaaS cards

Excessive rounded cards

Heavy gradients

Bright modern UI colors

Dashboard-style layouts

Excessive icons

Fake statistics

Fake testimonials

Invented company information

Copying Trocals directly

The Trocals reference should influence the visual language, editorial composition, navigation, storytelling and overall premium feeling, while the final website must have its own identity using the client's logo and brand.

Make the architecture reusable so future trips, destinations, experiences and galleries can be added without redesigning the website.

Image Direction Prompt

Use premium cinematic Indian travel photography throughout the website, inspired by the editorial visual quality of Trocals.

The imagery should feel authentic, luxurious, atmospheric and documentary-style, never like generic stock travel photography.

Prioritize:

Taj Mahal at sunrise/sunset

Old Delhi streets and architecture

Jaipur palaces, forts and Hawa Mahal

Indian heritage architecture

Local markets and artisans

Indian food and dining experiences

Traditional cultural performances

Rajasthani traditions

Travellers experiencing India naturally

Landscapes and atmospheric Indian scenes

Luxury travel moments

Image Style

Use photography with:

Cinematic natural lighting

Warm, earthy tones

Soft contrast

Rich architectural detail

Authentic people and environments

Editorial travel-magazine composition

Strong foreground/background depth

Negative space for typography

Wide compositions for hero sections

Portrait compositions for editorial sections

Avoid:

Obvious stock-photo poses

Overly saturated colors

Fake-looking AI people

Corporate business photography

Generic tourist selfies

Excessive filters

Cartoon/illustration styles

Images with visible text or watermarks

Image Placement

Use large immersive images rather than small repetitive cards.

Hero: cinematic Indian landscape/heritage image with enough negative space for large serif typography.

Destinations: one distinctive editorial image per destination.

Featured Golden Triangle Trip: combine Delhi, Agra and Jaipur imagery through large visual sections.

Itinerary: use destination-specific photography for each day.

Experiences: use full-width or large editorial images for Taj Mahal sunrise, rickshaw rides, Bollywood night, Rajasthani culture, food and bonfire experiences.

Gallery: use an asymmetric magazine-style image composition.

Maintain consistent photographic quality and color treatment across the entire website.

When generating AI images, preserve realistic Indian architecture, authentic Indian clothing, accurate monuments and culturally appropriate details.

The final photography should make visitors feel:

"I want to experience India like this."
